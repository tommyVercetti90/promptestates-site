In Jumeirah Village Circle, Object 1 is building TETR1S Tower: homes from studio to 2 bedrooms. The building plan is G + 3P + 16 floors. Handover is planned for Q2 2027, with construction at 12.2% by the last DLD inspection. Units on sale start from AED 887,328.
